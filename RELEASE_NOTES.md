Meteor Purple Edition v1.0.0 — Minecraft 26.2 / Fabric / Java 25.

This prerelease adds three live Catppuccin appearance profiles, nine movable HUD elements and optional OpSec status/notification integration. Install the actual Meteor 26.2, Catppuccin 2.4.0+mc26.2 and Fabric API 0.154.2+26.2 separately. Optional OpSec and Glazed must come from their official release pages.

The three themes are Catppuccin presets, selected in Purple Appearance. Purple Glass has translucent panels and HUD gradients; frosted blur is not implemented. Glazed is not redistributed or modified. See README.md and VALIDATION.md for installation, evidence and remaining compatibility limitations. This release is not a claim that every requirement of the original specification has been completed.
