# Meteor Purple Edition v1.3.0 · Zenith Moonrise

- Custom rotating colosseum panorama, actually built and captured in Minecraft 26.2.
- Three-tier oval arena, 48 bays, stepped seating, a ruined western arcade and a purple Meteor monument.
- Complementary Reimagined shader capture with cool moonlight, a visible setting moon, warm dawn, bloom and shadows.
- Zenith Client loading screen with the exact tagline “the client for the elite,” dark indigo styling and a lavender progress bar. Native reload lifecycle and error handling are retained.
- Six baked 1024×1024 images use Minecraft’s native panorama renderer. No live world or shader loader is required to display them. Performance/reduced-motion settings freeze rotation.
- Existing classic UI, ten themes, custom accents and editable Zenith HUD are retained.

Minecraft 26.2 / Java 25 / Fabric Loader 0.19.3+. Meteor, Catppuccin and Fabric API are bundled. Replace the previous Purple Edition JAR. Glazed and OpSec remain separate official installs; Glazed supplies ExploitPreventer. The upstream OpSec/EP metadata warning remains.

The panorama was captured using Iris 1.11.4 + Sodium 0.9.2 + Complementary Reimagined r5.9.3. Their binaries are not redistributed inside this addon. Source includes the actual block builder and capture setup. See VALIDATION.md for checks and limits.
