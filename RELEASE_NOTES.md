# Meteor Purple Edition v1.4.0 · Springy Zenith UI

- Clean floating Meteor-logo menu is now the default; the colosseum is an explicit optional backdrop.
- Meteor is the only large menu header mark. Rounded Comfortaa button text, subtle shadows, staggered entrances, hover lift, click compression and short sheen.
- Redesigned resource/world loading: smooth Comfortaa display type, floating logo, a rounded spring-following progress bar, bright cap and small progress spark bursts. The actual native loader still controls progress and completion; no artificial delay.
- UI animation toggle, reduced motion and performance overrides. Accessibility choices are available before Meteor initializes.
- Optional in-game Zenith HUD entrances/value glints and springy pause/options buttons; off by default. No camera shake or gameplay changes.
- The colosseum cubemap is loaded only when selected and released on return to the logo backdrop.

Minecraft 26.2 / Java 25 / Fabric Loader 0.19.3+. Meteor, Catppuccin and Fabric API are included; remove duplicate standalone bundled mods. Glazed and OpSec remain separate official installs, with EP supplied by Glazed. The existing upstream OpSec/EP warning is retained.

Choose backgrounds in Themes. Motion controls are in Purple → Purple Appearance. Existing classic UI, ten themes and editable HUD remain. See VALIDATION.md for evidence and limits.
