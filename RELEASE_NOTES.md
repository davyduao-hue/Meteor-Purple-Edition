# Meteor Purple Edition v1.5.0 · Zenith UI revamp

- Rebuilt classic category windows, module rows, settings controls and navigation. Responsive category wrapping, bounded scrollable bodies and a Search/Themes/Motion dock.
- Ten redesigned themes, each with its own shape language and 26 original icons: 260 symbols in compact atlases. Live preview cards show actual theme components.
- Bundled rounded Fredoka Medium typeface across menu, client screens and loading, with a fallback to the user's existing Meteor font preference.
- Animated seven-face Meteor assembly, float, pointer response, light sweep and click bounce/ring. Loading no longer consumes the menu's entrance animation behind its overlay.
- Spring feedback in module states, switches, buttons, slider thumbs, dropdowns, focus outlines and navigation. Staggered window entrances preserve saved positions.
- Gentle, Playful and Arcade presets, a separate particle switch, reduced-motion/performance overrides and optional game HUD/pause/options feedback.
- Native rounded panels submit one GUI state per surface; merged corner spans and resting-spring early exits reduce drawing/extraction work. No gameplay FPS multiplier claim.
- Real resource/world loading progress, branded typography, responsive bar impact/gloss/cap and bounded sparks. No artificial loading delay.

Minecraft 26.2 / Java 25 / Fabric Loader 0.19.3+. Meteor, Catppuccin and Fabric API are bundled; remove duplicate copies and replace the old Purple JAR. Glazed and OpSec remain separate official installs, with EP supplied by Glazed. The upstream OpSec/EP warning remains.

Classic category-window behavior is retained. Use custom-client-ui off for native Meteor, and custom-main-menu off for the native title screen. See VALIDATION.md for checks and practical limits.
