Meteor Purple Edition v1.1.0 — Minecraft 26.2 / Fabric / Java 25.

Install one JAR: official Meteor 26.2-35, Catppuccin 2.4.0+mc26.2 and Fabric API 0.154.2+26.2 are included as nested mods. Remove the old Purple Edition JAR and duplicate standalone copies of the included mods. Fabric Loader remains a separate installation.

New: ten coordinated themes including OS26 Glass and Original Meteor; custom home screen; live theme gallery; a unified, searchable module/settings/keybind hub; inline module toggles; smoother menu font and rounded geometry. Classic category windows and Minecraft's normal menu remain selectable.

Performance changes: cached HUD measurements and palettes, paginated module lists, event-driven toggle updates, adaptive blur, Performance mode and Reduced Motion.

The corresponding-source ZIP contains the complete Purple Edition project and the exact upstream Meteor/Catppuccin sources. It is part of this distribution's GPL source provision, not another mod to install.

Official Glazed was tested as a separately installed addon and appeared in the unified UI. Its license prohibits bundling. OpSec remains optional; Glazed's included ExploitPreventer has a declared conflict with OpSec 1.1.7.1. No protections are silently disabled.

This is a prerelease. Actual UI/theme rendering and bundle startup were tested; live-server behavior, all upstream features and comparative FPS benchmarks are not claimed. See README.md and VALIDATION.md for evidence and installation details.
